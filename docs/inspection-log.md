## Pass 4 (2026-09-11): the "floating GoPro mount"
The user saw the base fingers floating in Onshape. Cause: fingers, cradle and insert bosses overlapped their plates by only 0.01 mm, and Onshape did not fuse them, so the base and saddle each exported as two bodies. Fix: 1.0 mm overlap into the plate. The exporter now loads each STL and fails unless it is one manifold body. All six parts pass.
